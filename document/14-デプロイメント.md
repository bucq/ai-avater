## 14.3 環境別設定

### 開発環境

```bash
# frontend/.env.development
VITE_API_URL=http://localhost:8000

# backend/.env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4
GOOGLE_APPLICATION_CREDENTIALS=./service-account.json
ENVIRONMENT=development
DEBUG=true
```

### 本番環境

```bash
# frontend/.env.production
VITE_API_URL=https://YOUR_API_GATEWAY_ID.execute-api.ap-northeast-1.amazonaws.com/prod

# AWS Systems Manager Parameter Store (推奨)
/ai-avatar/prod/openai-api-key
/ai-avatar/prod/google-credentials

# または Lambda環境変数
OPENAI_API_KEY=sk-...
ENVIRONMENT=production
DEBUG=false
```

## 14.4 デプロイ手順

### バックエンド (AWS SAM)

```bash
cd infrastructure

# 初回デプロイ（ガイド付き）
sam build
sam deploy --guided
# Stack Name: ai-avatar-dev
# Region: ap-northeast-1
# Parameter OpenAIApiKey: sk-...

# 2回目以降
sam build && sam deploy

# 本番環境デプロイ
sam deploy --config-env prod
```

### フロントエンド (S3 + CloudFront)

```bash
cd frontend

# ビルド
npm run build

# S3アップロード
aws s3 sync dist/ s3://YOUR_BUCKET_NAME/ --delete

# CloudFrontキャッシュ削除
aws cloudfront create-invalidation \
  --distribution-id YOUR_DISTRIBUTION_ID \
  --paths "/*"
```

## 14.5 ローカル開発環境

### オプション1: FastAPI直接実行 (推奨)

```bash
# Backend
cd backend
python local_server.py  # → http://localhost:8000

# Frontend
cd frontend
npm run dev  # → http://localhost:5173
```

**利点:**
- 高速なホットリロード
- デバッグが容易
- IDE統合良好

### オプション2: SAM CLI (Lambda環境テスト)

```bash
cd infrastructure

# Lambda環境でテスト
sam local start-api
# → http://localhost:3000

# 特定の関数を直接実行
sam local invoke BackendFunction --event events/chat.json
```

**利点:**
- Lambda環境に近い
- 本番環境との差異が少ない

## 14.6 モニタリング

### CloudWatch Logs

```bash
# Lambda関数のログ確認
aws logs tail /aws/lambda/ai-avatar-backend --follow

# エラーログのみ表示
aws logs filter-pattern --log-group-name /aws/lambda/ai-avatar-backend \
  --filter-pattern "ERROR"
```

### CloudWatch Metrics

監視項目:
- Lambda実行時間
- Lambda エラー率
- API Gateway リクエスト数
- CloudFront キャッシュヒット率
