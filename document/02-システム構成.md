## 2.1 システム全体構成図

```mermaid
graph TB
    subgraph "フロントエンド (Vite + React)"
        UI[チャットUI]
        Avatar[3Dアバター表示<br/>Three.js + VRM]

    subgraph "バックエンド (AWS Lambda + FastAPI + Mangum)"

    end

    subgraph "AWS サービス"
        Bedrock[AWS Bedrock<br/>Nova Model]
        Polly[Amazon Polly<br/>Neural TTS]
    end

    User([ユーザー]) -->|テキスト入力| UI
    UI -->|HTTPS| API
    API --> Lambda
    Lambda --> AIService
    AIService --> Bedrock
    Bedrock -->|回答+感情| AIService
    AIService --> TTSService
    TTSService --> Polly
    Polly -->|音声データ| TTSService
    TTSService --> LipSyncService
    LipSyncService -->|音素タイムライン| Lambda
    Lambda -->|統合レスポンス| API
    API -->|JSON| UI
    UI --> AnimCtrl
    UI --> LipSync
    AnimCtrl --> Avatar
    LipSync --> Avatar
    Avatar -->|3D表示| User
```

## 2.4 データフロー

### 基本対話フロー

```mermaid
sequenceDiagram
    actor User
    participant UI as フロントエンド
    participant API as Lambda (FastAPI)
    participant Bedrock as AWS Bedrock
    participant Polly as Amazon Polly
    participant Avatar

    User->>UI: "こんにちは"
    UI->>API: POST /api/chat
    API->>Bedrock: 応答生成 + 感情分析<br/>(Nova Model)
    Bedrock-->>API: {text, emotion}
    API->>Polly: 音声合成<br/>(Neural TTS)
    Polly-->>API: audio.mp3
    API->>API: 音素抽出 (Rhubarb)
    API-->>UI: 統合レスポンス<br/>{text, audio, phonemes, emotion}
    UI->>Avatar: アニメーション開始
    Avatar-->>User: 3D表示 + 音声再生
```

詳細は [[06-AI対話機能#対話処理フロー|AI対話機能]]を参照

## 2.6 セキュリティ設計
